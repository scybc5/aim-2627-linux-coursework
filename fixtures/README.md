# 公开素材

`q1/`、`q3/`、`q4/`、`q5/` 是便于阅读的小样例，不是全部评分输入。正式用例由公开的 `tests/coursework.py` 生成，包含变化内容、空日志、动态端口和临时账户。

Q2 不依赖输入内容。Q3 的输出会预置待删除缓存，输入中的 tmp 必须保留。Q5 的工具路径、Q7 的密钥与 SSH 参数、Q8 的进程与服务参数、Bonus 的会话参数在自测时生成，不要将它们写死。

Q6 的 `.deb` 由同一份公开测试源码临时构建，没有维护脚本或网络依赖。`skeleton-sha256.json` 是原始答题骨架的校验表，只用于区分“模板初始化”与“已经修改但仍未实现”。退出 77 的检查始终记 0 分。

运行 `bash tools/test.sh` 会准备全部输入、执行答题脚本、生成反馈并清理临时环境，无需自己制作 SSH 服务或测试包。
